# kanji-practise-for-own-use
# 日本語総まとめ N3 漢字 — Week 1 Flashcards

Open `index.html` in a browser.

Features:
- 1日目〜7日目
- Kanji + readings
- Vocabulary combinations
- Burmese meanings
- Auto-generated romaji for vocabulary readings
- Reveal answer
- Previous / Next
- Random card
- Shuffle day
- Known / Review tracking
- Browser localStorage progress
- Keyboard shortcuts

Data follows the material supplied in the conversation. No backend or installation is required.
